# Varshikan K — Portfolio

Production-ready Vite + React + TypeScript personal site.

## Run locally

```bash
npm install
npm run dev
```

Add a portrait at `public/portrait.jpg` to replace the art-directed placeholder. Update links and project URLs in `src/data/content.ts`. Build with `npm run build` and deploy `dist/` to Vercel, Netlify, or GitHub Pages. The relative Vite base enables static hosting.
